Название: `TerraTectra Bots - @TerraTectraBotsBot`

Категория: `Игры и приложения` или `Другое`, если отдельной категории ботов нет.

- Живой GitHub Pages переведён на актуальные SEO-изменения в ветке `main`; исправлено прежнее расхождение, когда новые SEO-правки оставались только в production-ветке.
- Публично обновлены страницы `chat-ruletka-telegram.html` и `poisk-sobesednika-telegram.html`; усилены запросы «чат с незнакомцами» и «случайный собеседник».

- В TelegramRankings заявка принята успешно без e-mail. Запрошена категория `Telegram Anonymous Chat Bots`, которая на момент подачи показывала 0 карточек; редакционная проверка заявлена примерно до 48 часов.

- Опубликована отдельная SEO-страница `anonimnyy-chat-18-plus.html`, ранее готовая только в production. Она добавлена в живой `main`, sitemap и внутреннюю перелинковку.

### Автоматизация поискового продвижения

29.09 добавлен workflow `.github/workflows/indexnow.yml` в живую ветку `main`. Он автоматически собирает URL из `sitemap.xml` и отправляет их в IndexNow при изменениях HTML, sitemap, robots или RSS. Первые два запуска после установки завершились успешно. IndexNow теперь автоматизирован через GitHub Actions и не зависит от доступности Terra Control.
