# Анон-бот: собственный канал общения — подготовка без изменения продакшена

В этой ветке добавлен `anon-community-14d.json`: 14 полезных тематических публикаций с минимальной рекламной нагрузкой. Файл **не подключён** к `bot/content/channels.json`: публичный канал пока не создан/не выбран, поэтому запускать автопубликации рано.

## Какой результат нужен
- Отдельный тематический канал для существующего `@anon_gender_chat_ru_bot`.
- Вопрос дня, игровая тема и заметки о безопасности — подписчик получает пользу без обязательного запуска бота.
- Переходы по `?start=src_channel`; проверить существующий сбор источников, считать последующие поиски/пары/платежи отдельно.
- При создании канала получить реальный `chatId`, дать текущему боту право публикации.
- После проверки первого сообщения добавить **отдельную выключенную по умолчанию** запись в `bot/content/channels.json`, опубликовать первый пост вручную, затем включить автопубликацию.
- До публичного запуска сформулировать правила комментариев, назначить модерацию, избегать публикации частных переписок и анонимных жалоб.

**Важно:** не менять действующий поиск пар, платежи, хранилище и сервер; никакой автоматической публикации в этой ветке не включено.

## Другие независимые боты
Разработаны как отдельные локальные приложения: кружковая рулетка, знакомства, редактор постов, конвертер медиа и распознавание музыки. Не добавлять их в работающий анон-процесс: у каждого должны быть отдельный токен, база и канал.
